# 영화 티어리스트 웹페이지 기획서

**버전:** v1.0  
**상태:** 기획 완료 · 개발 전  
**목적:** 내가 본 영화를 취향에 따라 등급별로 분류하고, 완성한 티어리스트를 이미지로 친구들에게 공유하는 웹페이지

---

## 1. 서비스 개요

### 1.1 만들고 싶은 것

영화를 좋아하는 친구들과 이야기할 때, 내가 본 영화들을 S·A·B·C·D의 5개 등급으로 분류해 보여주는 개인용 영화 티어리스트 웹페이지를 만든다.

사용자는 영화를 검색하거나 직접 등록하고, 포스터를 원하는 티어에 배치한다. 완성한 티어리스트는 이미지로 저장하여 공유할 수 있다.

### 1.2 사용자와 목적

| 항목 | 확정 내용 |
|---|---|
| 주요 사용자 | 본인 1명 |
| 사용 목적 | 개인 영화 취향 정리 |
| 공유 대상 | 영화를 좋아하는 친구들 |
| 공유 방법 | 이미지 파일 |
| 사용 기기 | PC 및 스마트폰 |
| 계정 | 로그인 없이 사용 |
| 데이터 이동 | 파일 내보내기·가져오기 |

다른 사람이 직접 티어리스트를 편집하거나 여러 사람이 공동 작업하는 기능은 이번 버전의 범위에 포함하지 않는다.

## 2. 핵심 기능

### 2.1 영화 검색 및 등록

**자동 검색**
- 영화 제목을 검색한다.
- 검색 결과에서 영화를 선택해 목록에 추가한다.
- 영화 포스터, 제목, 개봉연도를 가져온다.
- 한국어 영화 제목을 검색할 수 있어야 한다.

**직접 등록**
- 자동 검색으로 찾을 수 없는 영화도 등록할 수 있다.
- 제목, 개봉연도, 포스터를 직접 입력하거나 선택한다.
- 등록한 영화도 일반 영화와 동일하게 티어에 배치할 수 있다.

검색 데이터 제공처 및 API는 개발 설계 단계에서 검토한다.

### 2.2 티어 분류

| 등급 | 의미(기본 제안) |
|---|---|
| S | 최고로 좋아하는 영화 |
| A | 매우 좋아하는 영화 |
| B | 좋은 영화 |
| C | 보통인 영화 |
| D | 아쉬운 영화 |

등급은 **S·A·B·C·D의 5단계로 고정**한다.

영화는 다음 두 가지 방식으로 배치한다.

- **드래그 앤 드롭:** 영화 포스터를 끌어 원하는 티어에 놓는다.
- **클릭 선택:** 영화를 클릭하면 등급을 선택할 수 있다.

이미 배치한 영화도 다른 티어로 옮길 수 있어야 한다.

### 2.3 초기화 및 되돌리기

- **개별 되돌리기:** 선택한 영화를 미분류 목록으로 이동한다.
- **전체 초기화:** 현재 티어리스트의 모든 영화를 미분류 상태로 되돌린다.
- 초기화는 등록된 영화 자체를 삭제하는 기능과 구분한다.
- 전체 초기화 전에는 확인 절차를 제공한다.

### 2.4 여러 티어리스트 관리

한 사람이 여러 개의 티어리스트를 만들 수 있다.

예를 들어 다음과 같이 구분할 수 있다.

- 인생 영화 TOP 티어
- 한국 영화 티어
- 애니메이션 영화 티어
- 친구에게 추천하고 싶은 영화 티어

각 티어리스트는 이름, 포함된 영화, 분류 결과를 별도로 관리한다.

티어리스트를 생성하거나 기존 목록을 선택하여 전환할 수 있어야 한다.

### 2.5 자동 저장

- 영화를 추가하거나 분류를 변경하면 자동 저장한다.
- 브라우저를 닫았다가 다시 열어도 이전 결과가 유지된다.
- 별도의 저장 버튼을 누를 필요가 없다.
- 각 티어리스트의 분류 상태를 독립적으로 저장한다.

저장은 우선 해당 브라우저의 로컬 저장소를 기준으로 한다. 브라우저 데이터 삭제 시 저장 내용이 사라질 수 있으므로 파일 백업 기능을 제공한다.

### 2.6 파일 내보내기·가져오기

PC와 스마트폰에서 동일한 자료를 사용하기 위한 기능이다.

**내보내기**
- 저장된 티어리스트 데이터를 파일로 추출한다.
- 영화 정보와 분류 상태를 포함한다.
- 여러 티어리스트를 함께 백업할 수 있어야 한다.

**가져오기**
- 저장한 파일을 다른 기기에서 불러온다.
- 티어리스트와 영화 분류 상태를 복원한다.
- 기존 데이터가 있을 때 덮어쓰기 여부를 확인한다.

이는 자동 동기화가 아닌 수동 파일 이동 방식이다.

### 2.7 이미지 저장

완성한 티어리스트를 이미지로 저장한다.

**이미지 필수 구성**
- 티어리스트 제목
- 저장 날짜
- S·A·B·C·D 등급
- 각 등급의 영화 포스터
- 영화 제목
- 개봉연도

이미지에는 검색창, 편집 버튼, 초기화 버튼 등 웹페이지 조작 요소를 포함하지 않는다.

저장 결과는 친구에게 바로 공유할 수 있는 형태여야 한다.

## 3. 화면 구성

### 3.1 기본 레이아웃

PC에서는 **왼쪽 영화 목록 / 오른쪽 티어표** 구조를 사용한다.

**상단 영역**
- 서비스 제목
- 현재 티어리스트 이름
- 티어리스트 선택 및 신규 생성
- 데이터 가져오기·내보내기
- 이미지 저장

**왼쪽: 영화 목록**
- 영화 검색창
- 검색 결과
- 영화 직접 추가
- 미분류 영화 목록
- 영화 포스터·제목·개봉연도

**오른쪽: 티어표**
- S등급
- A등급
- B등급
- C등급
- D등급
- 등급별 영화 배치 영역
- 개별 되돌리기
- 전체 초기화

### 3.2 모바일 화면

스마트폰에서도 검색, 추가, 분류, 저장 기능을 모두 사용할 수 있어야 한다.

PC의 좌우 배치는 작은 화면에서 사용할 수 있도록 반응형으로 전환한다.

모바일에서는 터치로 영화를 선택하고 티어를 지정하는 방식도 제공하여 드래그가 불편한 상황에서도 사용할 수 있도록 한다.

정확한 모바일 배치는 UI 설계 단계에서 결정한다.

## 4. 초기 영화 자료

첨부한 `아이디어.md`를 기준으로 다음 8편을 초기 테스트 영화로 사용한다.

| 번호 | 영화 |
|---|---|
| 1 | 기생충 |
| 2 | 인터스텔라 |
| 3 | 라라랜드 |
| 4 | 센과 치히로의 행방불명 |
| 5 | 어벤져스: 엔드게임 |
| 6 | 범죄도시 |
| 7 | 타이타닉 |
| 8 | 토이 스토리 |

위 목록은 영화 제목을 확인하기 위한 초기 자료이며, 포스터와 개봉연도는 실제 영화 정보를 조회하여 연결한다.

## 5. 주요 사용자 흐름

### 첫 이용

1. 웹페이지를 연다.
2. 새로운 티어리스트를 생성하고 제목을 입력한다.
3. 영화를 검색하거나 직접 등록한다.
4. 등록한 영화가 미분류 목록에 나타난다.
5. 영화 포스터를 드래그하거나 클릭하여 S~D 등급에 배치한다.
6. 원하는 대로 영화를 분류하고 배치를 수정한다.
7. 결과가 자동 저장된다.
8. 제목과 날짜가 포함된 티어리스트 이미지를 저장한다.

### 다시 이용할 때

1. 웹페이지를 다시 연다.
2. 기존 티어리스트를 선택한다.
3. 저장된 영화와 분류 결과를 확인한다.
4. 영화를 추가하거나 등급을 변경한다.
5. 변경 결과가 자동 저장된다.

### 다른 기기에서 이용할 때

1. 기존 기기에서 데이터 파일을 내보낸다.
2. 다른 기기에서 웹페이지를 연다.
3. 파일을 가져온다.
4. 저장된 티어리스트를 복원하여 사용한다.

## 7. 완성 기준 및 검증

웹페이지가 화면에 표시되는 것만으로 완료하지 않는다. 실제 사용 과정에서 다음 조건을 모두 통과해야 한다.

| 테스트 | 통과 기준 |
|---|---|
| 초기 영화 | 준비된 8편을 등록하고 분류할 수 있음 |
| 영화 검색 | 기존 목록에 없는 영화를 검색해 추가할 수 있음 |
| 직접 등록 | 검색되지 않는 영화를 수동 등록할 수 있음 |
| 드래그 | 포스터를 원하는 티어에 배치할 수 있음 |
| 클릭 | 클릭으로 티어를 선택할 수 있음 |
| 수정 | 배치된 영화를 다른 티어로 옮길 수 있음 |
| 초기화 | 개별 되돌리기와 전체 초기화가 정상 작동 |
| 자동 저장 | 새로고침과 브라우저 재실행 후 복원 |
| 다중 목록 | 여러 티어리스트의 분류 결과가 각각 유지됨 |
| 데이터 이동 | 내보낸 파일을 다른 기기에서 가져와 복원 |
| PC | 주요 기능이 정상 작동 |
| 모바일 | 주요 기능이 터치로 정상 작동 |
| 이미지 | 제목·날짜·등급·영화 정보가 포함된 이미지 저장 |
| 최종 공유 | 저장한 이미지를 실제 친구에게 공유할 수 있는지 확인 |

**최종 완료 조건:** 위 기능 테스트를 통과하고, PC와 스마트폰에서 실제 사용해 본 뒤, 친구에게 공유할 최종 이미지의 가독성과 결과를 확인하면 v1.0을 완료한 것으로 판단한다.

## 8. 개발 전 확인할 사항

현재까지의 선택으로 핵심 기획은 확정됐다. 개발 시 다음 사항은 추가 기술 검토가 필요하다.

1. **영화 검색 API:** 한국어 검색 지원, 포스터 제공, 사용량 제한 및 이용 조건
2. **포스터 이미지:** 저장한 티어리스트 이미지에 영화 포스터가 정상 포함되는지, 외부 이미지 사용 조건은 적합한지
3. **로컬 저장 및 백업:** 여러 티어리스트와 직접 등록한 포스터를 안정적으로 저장·이동하는 방식
4. **모바일 조작:** 작은 화면에서 티어 이동과 영화 선택을 편리하게 만드는 UI
5. **이미지 생성:** 영화가 많아지더라도 모든 등급과 제목이 잘리지 않도록 출력하는 방법
