# 습관 잔디밭

## 대상 사용자

- 매일 여러 습관을 기록하는 개인 사용자(PC·스마트폰 사용).

## 사용 목적

- 습관의 완료 여부를 체크하고, 최근 1년의 달성 현황과 통계를 확인한다.

## 화면 구성과 동작

- PC는 잔디밭과 습관 목록을 좌우로, 모바일은 세로로 배치한다.
- 최근 1년의 날짜별 달성률을 잔디 색상 진하기로 표시한다. 날짜를 누르면 해당 날짜의 습관을 체크·수정할 수 있다.
- 습관의 이름과 실천 요일(매일·특정 요일)을 설정하고, 보관·재활성화할 수 있다.
- 전체 달성률·연속 실천일·습관별 달성률 및 완료 횟수를 표시한다.

## 필요한 자료

- 사용자가 입력한 습관 이름, 실천 요일, 날짜별 완료 여부와 보관 이력.
- 브라우저에 자동 저장한 데이터 및 내보내기·가져오기용 JSON 파일.

## 완료 기준

- 습관을 추가하고 월·수·금으로 지정하면 해당 요일에만 실천 대상으로 나타난다.
- 하루 대상 습관 4개 중 3개를 체크하면 달성률 75%가 표시되고 잔디 색상이 변경된다.
- 과거 날짜의 체크를 바꾸면 잔디·통계가 즉시 갱신된다. 실천 대상이 없는 날은 달성률 계산에서 제외된다.
- 습관 보관·재활성화 후에도 과거 기록이 유지된다.
- 새로고침 후 기록이 남고, JSON 파일로 백업·복원된다. 잘못된 파일은 거부하고 덮어쓰기 취소 시 기존 데이터를 보존한다.
- 초기화 취소 시 기록이 유지되며, 확인한 경우에만 삭제된다.
- 연도 경계와 윤년 2월 29일을 올바르게 표시한다.
- PC·모바일에서 사용 가능하며, 로그인·서버·외부 파일 없이 단일 HTML로 오프라인 실행된다.

## 추가 기능

- 오늘 날짜 강조, 날짜별 달성률 툴팁, 습관 표시 순서 변경.

## 한계 및 비목표

1. 계정 로그인, 서버 연동, 기기 간 자동 동기화는 지원하지 않는다.
2. 알림·푸시 메시지·자동 추천 기능은 구현하지 않는다.
3. 시간·횟수 목표나 사용자 간 공유 기능은 제공하지 않는다.

## 검증 방법

- 매일 습관 4개를 3일 동안 각각 2개·3개·4개 완료 처리한다. 날짜별 달성률 50%·75%·100%, 전체 달성률 75%(9/12)가 화면 수치와 일치하는지 손으로 계산해 비교한다.
- 연도 경계·윤년·대상 습관이 없는 날, JSON 복원·초기화 취소, PC·모바일 오프라인 실행을 직접 시험한다.
