# 오늘의 할 일 체크리스트

## 대상 사용자
- 오늘 해야 할 일을 간단하게 관리하려는 개인 사용자 1명

## 사용 목적
- 오늘 해야 할 일을 기록하고 완료 여부를 확인한다.

## 화면 구성과 동작
- 상단에 '오늘의 할 일 체크리스트' 제목을 표시한다.
- 할 일 입력창과 추가 버튼을 배치한다.
- 내용을 입력하고 Enter 키 또는 추가 버튼을 누르면 목록에 추가된다.
- 할 일은 등록한 순서대로 표시된다.
- 체크박스를 누르면 완료 상태가 되고 취소선이 표시된다.
- 체크박스를 다시 누르면 미완료 상태로 돌아간다.
- 각 할 일의 삭제 버튼을 누르면 목록에서 제거된다.
- 할 일이 없으면 '할 일을 추가해 보세요'라는 문구를 표시한다.
- 변경 내용은 브라우저에 자동 저장한다.

## 필요한 자료
- 사용자가 직접 입력하는 할 일 내용
- 초기 목록은 비어 있으며 별도의 외부 자료는 필요하지 않다.

## 완료 기준
- 할 일을 입력하고 추가하면 목록에 표시된다.
- 완료 체크 시 취소선이 표시되고, 체크 해제 시 원래대로 돌아온다.
- 삭제 버튼을 누르면 해당 할 일이 제거된다.
- 새로고침하거나 브라우저를 다시 실행해도 저장된 목록과 완료 상태가 유지된다.
- 날짜가 바뀌어도 기존 목록이 유지된다.
- PC와 모바일 화면에서 사용할 수 있다.
- 로그인이나 서버 없이 HTML 파일 하나로 실행된다.

## 추가 기능
- 이번 구현에서는 추가 기능을 포함하지 않는다.

## 한계 및 비목표
1. 로그인, 일정 관리, 알림 기능은 구현하지 않는다.
2. 완료 개수, 진행률, 중요도 설정, 순서 변경 기능은 제외한다.
3. 데이터는 사용 중인 브라우저에 저장되며 다른 기기와 자동 동기화되지 않는다.

## 검증 방법
- 할 일을 추가한 뒤 목록에 표시되는지 확인한다.
- 체크박스를 선택하고 해제하며 취소선 표시가 변경되는지 확인한다.
- 삭제 버튼을 눌러 해당 할 일이 사라지는지 확인한다.
- 새로고침 및 브라우저 재실행 후 기존 기록이 유지되는지 확인한다.
- PC와 모바일 화면에서 입력, 체크, 삭제 기능을 확인한다.
