# 미션 3 기록

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| 저장 기능 없음 | 다시 열면 초기화됨 | 반영 | 기획서와 다름 |
| 초기화해도 추가 영화가 남음 | 초기화하면 사라짐 | 보류 | 정상 작동함 |
| 빈 제목 추가 가능 | 빈 카드가 생김 | 반영 | 수정 필요 |
| 모바일에서 불편함 | 오른쪽 화면이 잘림 | 반영 | 모바일에서도 볼 수 있어야 함 |
| 이동 방법이 헷갈림 | 구체적인 상황이 불분명함 | 되묻기 | 어떤 동작이 헷갈렸는지 질문 |
| 드래그가 불편함 | 아래에서 위까지 끌어야 함 | 반영 | 이동 동선이 김 |
| 색이 칙칙함 | 개인 취향 차이 | 보류 | 기능상 문제 없음 |
| 포스터 추가 요청 | 제목만 표시됨 | 보류 | 기획서 필수 기능 아님 |
| C등급 삭제 요청 | 정상 작동함 | 보류 | 기획서에 정한 등급 |


- 아무도 말하지 않았는데 내가 찾은 것:기존 영화와 같은 제목을 추가하면 중복 카드가 생김. 중복 등록을 막으면 좋겠음.
